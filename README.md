# 📊 Superstore Sales Analysis (Power BI)

## 🚀 Project Overview

This project presents an interactive Power BI dashboard analyzing Superstore sales data to uncover key business insights across revenue, profit, customer segments, and regional performance.

The dashboard enables stakeholders to monitor performance, identify trends, and make data-driven decisions.

---

## 📌 Key Features

* 📈 Total Revenue, Profit, Quantity & Profit Margin KPIs
* 🗺️ Sales analysis by State and City
* 📦 Sales breakdown by Category & Sub-Category
* 🚚 Shipping mode performance analysis
* 👥 Customer segmentation (Consumer, Corporate, Home Office)
* 🎛️ Interactive filtering using slicers

## 🧠 Key Insights

* Consumer segment contributes the highest share of total sales
* Standard Class shipping mode dominates order distribution
* Phones and Chairs are among the top-performing sub-categories
* Sales are concentrated in major cities like New York and Los Angeles
